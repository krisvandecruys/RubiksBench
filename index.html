Scores

Validity says how close an image comes to a valid, scrambled, standard 3x3 cube: the fewest stickers you would have to recolor to get one (plus any sticker no recoloring fixes, such as one with letters or two colors), compared with random colors. 100% is a valid cube, 0% is no better than coloring the stickers at random (which needs about 4.4 recolorings, because the three hidden faces leave a lot of freedom). An image that is not read as a 3x3 cube scores 0%.

The rubric explains what is wrong: up to 15 points, 1 per check passed, ½ when inconclusive, 0 when failed or blocked (see Checks). An image passes only if it passes all checks. Scores are over generated images; requests that returned no image are counted separately as generation errors.
